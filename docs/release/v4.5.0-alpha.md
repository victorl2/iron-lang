# Iron v4.5.0-alpha: Temporaries, Pointers and the Manual

Every parked acceptance fixture is now a real test, the reference manual describes the language as implemented (and its verification found a dozen compiler bugs, fixed here), and a set of lifetime and pointer holes are closed. This is an **alpha** release; the surface may change before GA.

## Language and compiler

- **Temporaries are dropped.** A field or element read off an owned temporary (`make_probe().name`, `build()[0]`) copies the value out and drops the temporary; a list field moves out of it; a `for` loop drops a temporary iterable when it finishes. Such temporaries used to leak, and a list element bound from `get()` was dropped twice.
- **Closures keep their counters.** A `var` that a closure captures moves into a reference counted cell shared by the declaring frame and every closure env, so a closure that writes it may be returned or stored (`make_counter`). It used to point into the dead frame.
- **Field narrowing.** `if p.nick != null` and `if s.shape is Square` narrow the field for the branch when the path is rooted at an immutable binding; a `var` root still reports E0204.
- **Slicing.** `xs[a..b]` on a list or fixed array is a new list of the elements in `[a, b)`, `xs[a..]` runs to the end; string slices stay substrings.
- **Functions as values.** A named top-level function can be passed, bound and stored (`apply(twice, 4)`, `val f = twice`, `[twice]`).
- **Strings.** `<`, `<=`, `>`, `>=` compare bytes; `s += t` joins. A compound assignment its target type does not support is E0202.
- **Interfaces.** `-> Self` in an interface method resolves to the implementor on a concrete call and to the interface on a dynamic one.
- **Objects.** An object with both `init` and `copy` constructs; a field of the object's own nullable type reports E0223 (use `rc T?`, which works as a linked list).
- **Types and literals.** `rc [Iface]` literals take the annotated element type, `rc T?` names the nullable strong handle `upgrade()` returns, and a list literal adopts an expected `[T; N]`.
- **Pointers.** Heap and rc generations come from a process wide counter, so a stale pointer stays stale when the allocator reuses the address (it used to revalidate). `&list[i]` on a growable list is rejected with **E0330** unless written directly as a call argument. A checked pointer to a scalar (`*Int`) prints its pointee. `Ptr.offset` / `Ptr.diff` compile.
- **Match.** Duplicate integer arms are E0226; a nested pattern is allowed only when the inner enum has a single variant (**E0332** otherwise), since the arm is selected on the outer tag alone.
- **Diagnostics.** List extension methods with a body are **E0331** (only the stdlib's intrinsic stubs exist). W0600 is retired: a standalone `spawn` is a deliberately detached task.
- **Performance.** A string literal is interned once per program instead of on every evaluation; a closure returned by a call and invoked in the same expression no longer leaks its environment.

## Manual

`docs/language_definition.md` is rewritten as a single-page reference manual of the language as implemented, with a complete EBNF grammar checked against the fixture corpus. Features that were described but never built are gone, wrong descriptions are corrected, and every implemented surface is documented. Every code block is compiled, run and compared against its printed output by the doc test; an untagged block fails CI.

## Tests

- The 23 remaining `phase-38` fixtures are unparked: fixed, rewritten in current syntax, re-authored to the documented semantics, moved to the negative corpus, or removed. Only the Map and Set fixtures stay parked (#193).
- `tests/run_tests.sh` builds and runs fixtures on a worker pool (`IRON_TEST_JOBS` overrides its size), with the report replayed in corpus order. The acceptance suite drops from about 15 minutes to a few.

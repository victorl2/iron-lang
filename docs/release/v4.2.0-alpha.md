# Iron v4.2.0-alpha: LLM Docs and Cleanup

A small release focused on documentation for coding assistants, compiler diagnostics, and cleanup. This is an **alpha** release; the surface may change before GA.

## llms.txt for coding assistants

ironlang.dev now follows the [llms.txt](https://llmstxt.org) convention:

- [`/llms.txt`](https://ironlang.dev/llms.txt): a short index with the key rules for writing Iron and links to everything below
- [`/llms-full.txt`](https://ironlang.dev/llms-full.txt): the language guide, networking guide, stdlib declarations, and runnable examples in one file
- [`/llms/iron.md`](https://ironlang.dev/llms/iron.md): a concise language guide written for LLMs, plus one markdown page per stdlib module under `/llms/stdlib/`

Every example in the guide is compiled in CI, so it describes the syntax the compiler accepts today, including the current known gaps. All files are generated from the repository at deploy time.

## Compiler

- **W0613 no longer suggests `val` for bindings `val` rejects.** The "var binding never reassigned; declare as 'val'" warning, and W0614 for parameters, now stay quiet when the binding is used through a mutating method call, a field write, a `var` or `*var` argument, or `&` producing `*var T`. Following the old suggestion failed with E0235, E0234, or E0267.
- **`val xs: [T] = []` compiles.** An annotated `val` now passes its type to an empty list literal, as `var` already did, instead of failing with E0229.
- **Clearer errors for removed v2 syntax.** Errors for `mut`, receiver methods, inline field defaults, and objects without an `init` now show the syntax to use.

## Removed

- The `ironc migrate` command and the v2-to-v3 codemod
- The LSP `iron.migrate` command and its quickfix, and the VS Code and Neovim commands that invoked it
- The v2-to-v3 and v3-to-v4 migration guides

## Release archives

The `iron-<version>-<target>.tar.gz` downloads are now packaged through the CMake install rules. The v4.0.0-alpha and first v4.1.0-alpha archives were missing `lib/diagnostics/`, so the downloaded `ironc` could not compile any program. The release job now compiles and runs a program with each archive before uploading it.

## Install

```sh
curl --proto '=https' --tlsv1.2 -sSfL https://ironlang.dev/install.sh | sh -s -- --version v4.2.0-alpha
```

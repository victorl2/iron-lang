# Iron v4.3.0-alpha: Correctness and Interfaces

A correctness release: dozens of compiler bugs fixed, each with a regression test, and first-class interface values. This is an **alpha** release; the surface may change before GA.

## Breaking changes

- **Lists are never copied implicitly.** A list has one owner. `val b = a` on a list place is an error (E0328): write `a.copy()` for a deep copy or `a.take()` to move it out and leave `a` empty. Passing a list to a function lends it. List mutators and index writes need a `var` binding.
- **`extends` and `super` are removed.** `impl` is the only conformance keyword.
- **Strings are character based.** `len` and indexing count characters; use `byte_len` for bytes.
- **Interface lists keep insertion order.** Iterating a `[Shape]` visits elements in the order they were added. Grouping by implementor now needs `[Shape, unordered]`, which cannot be indexed (E0329).
- **Named arguments are rejected.** `f(name: value)` reports that arguments are positional.
- `pub` visibility is enforced across files, and a binding whose type has a destructor must be initialized where it is declared (E0327).

## Interfaces

- **Type tests.** `x is Circle` checks which implementor an interface value holds, and `x is Named` checks whether it implements another interface. Inside the branch, `x` is the implementor: read its fields, and write them when the binding is `var`. A test on a value whose type is already known warns (W0615).
- **Type match.** `match shape { Circle(c) -> ... Square(s) -> ... }` over an interface value, including a nullable one (with an `else` arm for null). Arms are checked for duplicates, for non-implementors, and for exhaustiveness.
- **Flow narrowing.** Null checks and type tests narrow through `not`, `and`, `or`, `elif` chains and early returns (`if not (sh is Circle) { return }`).
- **Interface values and lists own their data.** Interface values are dropped at scope exit and deep copied by `.copy()`. `[Iface]` lists support `copy`, `take`, `xs[i] = v`, `set`, `insert`, `remove`, `clear`, `reverse`, `filter` and `map`, and work as object fields.
- **Lists of lists.** `[[T]]`, including elements that own lists, copy deeply; list literals take their element type from context.

## Compiler fixes

- **Value lifecycle.** Each copy of an object with a destructor is dropped once, copy hooks run on copies, `return local` moves, and temporaries are dropped.
- **Memory.** Lists are freed through their owning binding on every path. Several leaks and double frees with interface values and lists are fixed, found with ASan and the macOS `leaks` tool.
- **Type checking.** `elif` bodies after a null check or type test are checked again; narrowing no longer leaks from one function into another; an `if`/`elif`/`else` only counts as returning when every branch does.
- **Diagnostics.** One parse error per statement instead of a cascade. Field access on a type without fields is an error (E0219). Compiler crashes are reported as crashes.
- **Numbers.** Numeric literals take their contextual type with a range check, and floats print in shortest round-trip form.
- **Runtime.** stdout is flushed before panics and leak reports, and runtime and language server threads get an 8 MB stack.
- **Language server.** A data race in the generics instance table is fixed.

## Testing

Every runnable fixture is now built with and without optimization and the two programs are compared (`test_opt_parity`). Every fix has a regression test, and the suite runs under ASan, UBSan and TSan.

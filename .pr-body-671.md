## Summary

- Inline list, string, fixed-array, and bounded-vector lengths in generated C so loop bounds are visible to clang.
- Emit fixed-array and bounded-vector checks as unsigned range comparisons, preserving the existing panic text while allowing redundant checks to disappear.
- Inline string byte length and byte access through pointer-based helpers, avoiding runtime calls and by-value string copies.
- Emit eligible immutable global `val` tables as `static const` data while preserving dynamic initialization order for nonconstant globals.
- Evaluate comptime bitwise operators and shifts with the same width, signedness, and edge-count behavior as runtime operations.
- Add generated-C, runtime, compile-fail, fuzz, and benchmark coverage for these paths.
- Reserve CTest capacity for internally parallel fuzz and corpus runners so the documented four-way suite does not oversubscribe them.

This is the code-generation portion of #658. Language-design items from that proposal remain out of scope.

## Generated code

The list sum on `origin/main` reloads the length through a runtime call on every iteration and retains a panic branch:

```asm
call   Iron_List_uint8_t_len
...
cmp    %rcx,%r14
jae    <panic>
...
call   Iron_List_uint8_t_len
```

On this branch, clang sees the count and data directly, removes the redundant check, and unrolls eight bytes at a time:

```asm
movzbl (%rcx,%rdi,1),%r8d
...
movzbl 0x7(%rcx,%rdi,1),%eax
add    $0x8,%rdi
cmp    %rdi,%rsi
jne    <loop>
```

The string quote scan on `origin/main` copies the string value and calls `Iron_string_byte_at` for each byte. On this branch there are no string accessor or panic calls in the hot function, and clang emits packed byte comparisons:

```asm
movzwl (%rdx,%rax,1),%edi
pcmpeqb %xmm1,%xmm4
punpcklbw %xmm4,%xmm4
paddq  %xmm4,%xmm2
add    $0x4,%rax
jne    <loop>
```

## Benchmark

Linux x86_64, Intel Core i7-13700K, pinned to CPU 2, 32 MB input, best of 11 runs. Both revisions used the same Release configuration and clang toolchain. Baseline is `origin/main` at `381ea1be`.

| case | main | branch | speedup |
| --- | ---: | ---: | ---: |
| list byte sum | 21.996 ms | 5.095 ms | 4.32x |
| list quote count control | 9.129 ms | 9.238 ms | 0.99x |
| string quote count | 64.873 ms | 9.258 ms | 7.01x |
| constant-table classify | 31.352 ms | 7.243 ms | 4.33x |
| tokenizer | 98.359 ms | 29.756 ms | 3.31x |

The control case is intentionally unchanged. The benchmark source, pinned runner, throughput output, and disassembly commands are under `tests/benchmarks/byte_loops`.
